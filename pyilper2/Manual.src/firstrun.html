Welcome to pyILPER 2

You are probably using pyILPER for the first time. A default configuration has just been created for you, consisting of an interface for the PIL box, the scope, a printer, a terminal, and two mass storage devices.

The first thing you need to do is configure the interface. If you want to use a PIL box, connect it now and enter the PIL box device in the tab named Interface1. Next, you should specify a suitable working directory in the PIL box configuration.

If have completed the basic configuration you can start the pyILPER loop from the File menu. While working, keep the help window open to consult the online help system to become familiar pyILPER.
