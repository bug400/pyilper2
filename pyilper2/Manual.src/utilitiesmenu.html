Utilities Menu Entries

Initialize LIF image file

Initialize a LIF image file. Various media types, the number of directory entries and an optional label can be specified. This utility allows the initialization of media types that can not be created from the HP-71 by default.

Warning: Do not initialize a LIF image file that is mounted to a virtual drive.

Note: this menu entry is only accessible if the latest version of the LIFUTILS is installed.

Fix header of LIF image files

Some HP-IL controllers do not initialize the LIF image file header properly. pyILPER will issue a warning if the image file header does not contain valid medium size information. This menu entry fixes this information. Be careful to specify the proper medium type.

Warning: do not initialize a LIF image file that is mounted to a virtual drive.

Note: this menu entry is only accessible if the latest version of the LIFUTILS are installed.

HP-IL device status

This menu entry shows a pop up window with that shows all devices that exist in the pyILPER virtual loop:

  • Virtual HP-IL devices (printers, terminals, drives etc.) and their status
  • Interfaces
  • Probes

The status information for devices includes the current HP-IL device ID, the accessory ID, the HP-IL address (simple and extended), and the internal HP-IL status of the virtual device.

The status information is updated every 500 ms.

Copy PILIMAGE.DAT to workdir

Copies the LIF image file that contains software to set up the terminal emulator for the HP-71B to the current working directory.

Check LIFUTILS installation

Display diagnostic information if a valid LIFUTILS version was found on the system.
