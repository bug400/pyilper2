Troubleshooting

On this page, you'll find suggestions for solving problems, organized into the following categories:

  • Program Start
  • Loop start
  • PIL-Box Interface
  • TCP/IP Interface
  • General Application Errors
  • Terminal
  • Drive
  • HP82162A Thermal Printer
  • HP7470A Plotter

Program Start

Program does not start or crashes unexpectedly

Most problems are related to corrupted configuration files.You can find this out very easily by starting pyilper with the default configuration and a new instance: 

python -m pyilper2 --clean --instance temp

This creates a new default configuration for the instance temp, which does not affect your current configuration.

If this does not help, you need to check the error messages pyILPER writes to standard error. Run the program from the command line:

python -m pyilper2

Watch for messages displayed on the console. There are two types of error messages to distinguish between

  • Python errors: A Python error message (traceback) can be recognized by a structured text output in the terminal, which usually begins with the line `Traceback (most recent call last):`. Python provides detailed information about where (file, line number) and what type of error occurred. This error message is usually caused by a programming error in pyILPER or configuration file problems (see below).
  • Other errors: Other error messages that can mean all sorts of things usually indicate installation problems or incompatibilities of the Python or Qt software and your operating system.

It is known that older versions of display drivers crash pyILPER at startup if the program tries to run the internal web browser. Try to start pyILPER with:

python -m pyilper2 --use-system-browser

This option instructs pyILPER to use the system default web browser instead of the integrated PySide6 browser.

In any other case, issue an error report on GitHub

Error message: Cannot change to working directory

The application did not succeed in changing the working directory to the configured file path. Check the path and permissions.

Error message: Your configuration files are of the pyILPER version: XXX that is newer than the version you are running. The program might crash or misbehave. Do you want to continue?

You probably downgraded pyILPER to an older version. The current configuration files might contain data that are not compatible with the running version. To avoid problems, you should reset the configuration files. See the section above.

Loop Start

If the loop terminates with an error message when it starts or remains in the “waiting for connections” state, the cause is incorrect or incomplete interface configurations. Please read the instructions for the interfaces below.

PIL-Box Interface

The status light for the PIL-Box interface stays "yellow"

The serial device you specified in the interface settings does not exist. Please check at the operating system level whether the device specified in the configuration is active.

The connection to the PIL-Box is terminated with an error message

Errors like baudrate mismatch or cannot reset device indicate access issues with the interface. It is possible that another process is already using it.

A timeout error indicates that the connected device is either not a Pil-Box or that the connected Pil-Box is taking too long to become operational.

TCP/IP Interface

The loop does not start with the error message TCP/IP: cannot bind to port

The port number you specified as In Port is probably used by another program.

I started all my Virtual HP-IL over TCP/IP programs, but the status of the interfaces stays "yellow"

That's normal. Generate some network traffic, for example, by performing a “restore io.” That's what establishes the network connections.

Generating network traffic results in a HP-IL loop timeout

There is something wrong with the configuration of the TCP/IP interfaces in pyILPER or the other Virtual HP/IL over TCP/IP programs. See the Virtual HP-IL Example for a working configuration, and carefully check the TCP/IP connection parameters of all programs that are components of the TCP/IP loop.

General application error messages

Error messages related to log file processing

Log files are created in the pyILPER working directory. They are named after the corresponding tab and end with “.log.” Please check the disk space and access permissions for the log file and the pyILPER working directory.

Error messages related to reading or writing configuration files

The locations of the configuration files are:

PlatformDirectory
LINUX$HOME/.config/pyilper
Windows%HOMEDRIVE%%HOMEPATH%\pyilper2_config
Mac OS X$HOME/Library/Application Support/pyilper
Other$HOME

Please check the disk space and access permissions for the files in the directory mentioned above.

Terminal

The HP-71 keyboard does not work

If you use the PIL-Box interface, you must check the Enable IDY frames option. In addition, the program PILTERM must be run. See the documentation about the terminal for details.

Drive

The File Management Controls are disabled

You need to install the required version of the LIFUTILS. In addition the Device enabled option must be unchecked. This is a safety measure to prevent HP-IL and LIFUTILS operations from being performed simultaneously on a LIF image file.

Error messages: File does not contain a LIF type 1 medium and XXXXX

A LIF1 file header is missing, and therefore the file is not opened. If you are certain that this is a LIF1 image despite the missing headers, you can repair the header of this file. Be sure to make a backup copy first.

Warning message: File does not contain a LIF type 1 medium with valid layout information. Using default layout.

The LIF image file does not contain a properly initialized header with valid layout information. The default layout is used.

Warning! If the default layout does not match the current medium, data corruption may occur! It is recommended to fix the header on a copy of the file.

HP82162A Thermal Printer

There is no print output from V41 or an HP-41 connected to a PIL-Box and/or the function keys of the printer tab do not work.

Always place the tab of the HP82162A termal printer directly after the Interface tab, to which the HP-41 controller is connected. If an HP-41 controller is connected to a PIL-Box, make sure that the Enable IDY Frames option is set.

Plotter

The status light of the plotter stays red

You need to install the required version of the LIFUTILS that contains the backend program to run the plotter.
