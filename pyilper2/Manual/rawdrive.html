Raw Drive Tab

Description

This virtual device emulates a raw drive for access to non-LIF media. This device can be used by HP-IL controllers that do not use the LIF file system, like the HP-110 portable computer. The drive is configured by specifying a Device ID and a Medium type.

If you would like to use pyILPER as an HP-IL device emulator for the HP 110 Plus or HP Portable Plus computer, you should read J.-F. Garnier's HP 110 Plus / HP Portable Plus Resource Page first.

To set the Device ID choose one of the predefined values below or enter an arbitrary identifier.

Device IDAccessory IDDefault Address

The capacity of the drive is specified by the Medium type. The following media types are available:

Medium typeCapacity
HP82161A cassette131.072 Bytes
HP9114B double-sided disk630.784 Bytes
HDRIVE1 640K disk655.360 Bytes
HDRIVE1 2MB disk2 Megabyte
HDRIVE1 4MB disk4 Megabyte
HDRIVE1 8MB disk8 Megabyte
HDRIVE1 16MB disk16 Megabyte

Note:The HP Portable can only format HP82161A cassette media. If you would like to use media with a higher capacity, you need appropriate image files initialized with an MSDOS file system. Image files with a capacity of 640 KByte, 4 MByte and 16 MByte can be downloaded from J.-F. Garnier's web page.

Device Controls

The drive tab has the following controls:

  • Raw image file Change button: mount a disk file that contains the image of a non-LIF medium. The file must already exist and must match the selected Medium type.
  • Medium type combo box: Choose the proper medium that shall be emulated (see above).
  • DID combo box: Choose the DID for the drive.
  • Device enabled: If checked, the virtual HP-IL drive is available and can be used as an HP-IL device. The HP-IL loop must always be reconfigured after activation or deactivation.
